# Do You Know the Actual Cost of Your Medications?

This project was completed as part of Carnegie Mellon University's 05-619: Data Visualization course. It is an interactive data story that compares brand-name and generic drug prices using [National Average Drug Acquisition Cost (NADAC) data](https://www.medicaid.gov/medicaid/nadac) from the Centers for Medicare & Medicaid Services (CMS). The goal was to help pharmaceutical reform organizers advocate for fairer drug pricing.


## Installation and Usage
Follow these steps to set up the project locally:

1. **Clone the Repository**
```bash
git clone https://github.com/anissakp/NADAC-Data-Story.git
```

2. **Install Dependencies at Root Directory**
```bash
cd NADAC-Data-Story
npm install
```

3. **Start Development Server**
```bash
npm run dev
```
